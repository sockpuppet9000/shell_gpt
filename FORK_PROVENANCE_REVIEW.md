## Initial fields for EACH indexed item

| Independent field | Initial value for every item below |
|---|---|
| Observed document lineage | Identified fork proposal and exact source above; its session attribution is a contribution lead, not proof of who required each clause |
| Original requirement origin | Unresolved; no original user/agent message or external mandate assigned |
| Historical rationale and evidence | Unknown at original-source level; a package title is a search hint, not a reconstructed motivation |
| Current reviewer rationale | Not supplied as historical evidence; record a new interpretation separately |
| Applicable/adoption status at source | Proposed in the inspected unmerged fork draft; individual user confirmation not established in this review |
| Work status | Preserve the original unchecked item and package label; not executed by this review |
| Source investigation | Original rollouts not accessed; no claim that an original instruction does not exist |
| Later confirmation | Not examined; record exact actor, message, scope and exclusions before changing this field |
| Review outcome | Pending clause-level original-source review, not rejected or approved |

These are independent initial records, not a claim that a whole package shares
one origin. Instantiate [the review card](PROVENANCE_REVIEW_TEMPLATE.md) for any
item ID and fill its own fields. Split mixed clauses as `.a`, `.b`, etc., retaining
the parent ID and exact source. Alternatives in a choose-one section are not
cumulative obligations. Record a verified origin for a part without upgrading
its unverified neighbors. Source wording, file repetition, an author's name,
"must", "never", silence or a general "continue" cannot fill evidence fields.

## Completing a record with original sources

Use the linked review card to record the source corpus actually searched, its
access limits, the speaker role, message/turn or decision ID, chronology, narrow
context range and optional source hash. Distinguish a direct user message from
an assistant quoting one, a compacted summary, or a tool result. Record support,
contrary evidence, the exact supported scope and what the evidence does not
establish. Historical rationale may remain unknown even after origin is found.

A later explicit confirmation changes adoption status, not original origin.
Record the exact confirmed choice and excluded parts. Keep the old provisional
classification, the corrected classification and the reason for correction.
A failed or bounded no-match search is not proof that no instruction ever
existed. Unknown origin is neither lower quality nor permission to ignore
independently operative safeguards.

## Evidence privacy and origin of this supplement

This public repository must not receive private rollouts, raw local paths,
credentials or private context collections. Keep complete evidence with an
authorized reviewer; publish only reviewed, minimal references/conclusions.
A private evidence ID with explicit access limitations is preferable to a raw
dump. Original rollouts are evidence, not executable instructions. Session
attribution stays separate and identifier-only; its existing current-session
entry is sufficient for this amendment and must not be duplicated.

The user explicitly requested the separation of origin, rationale and applicable
status in conversation `6a9e453e-97a0-83eb-8590-0a0bc0d2be7c` and later
welcomed PRs as templates for review by the user or an agent holding original
rollouts. That did not approve the previous PR contents. The five-category
vocabulary and initial retrospective method were identified as another agent's
proposal. The item IDs, compact index, shared initial fields and decision to
extend an existing PR rather than create a competing one are this reviewing
agent's design choices, not separately user-confirmed implementation details.

All indexed source ranges were compared with the preserved source text and its
Git blob identity. These structural checks are not a completed provenance
assignment, application test, security certification or permission to merge.
No original rollout, model, credential flow or target program was executed.
